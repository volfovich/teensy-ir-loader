# The "rock" kit: our own kick, snare and closed hi-hat (originals/), and the
# rest from the AVL Drumkits "Red Zeppelin" (CC-BY-SA 3.0, see CREDITS.md).
#
# tools/import_kit.py builds the WAVs here from the source samples;
# tools/make_kits.py compiles the WAVs into the firmware.
#
#   name     command name (at most 9 characters); title: display name (13)
#   order    position in the kit list (kit numbers are saved in settings,
#            so a new kit goes last)
#
#   lane     kick snare rim hatc hato ride crash tomh (rack tom) toml (floor tom)
#   vel      the velocity the sample is for, 1..9 (the AVL layers 1..5 are
#            velocities 1, 3, 5, 7, 9). A hit plays the sample nearest its
#            velocity, scaled by hit velocity / sample velocity.
#   max/fade the length kept and the fade-out at its end, in seconds
#   source   a file in this folder (originals/Kick1.wav), or else a file
#            under the `source` URL
#   peak     the lane's level at velocity 9 (dBFS); each sample peaks at
#            peak x vel / 9. `-` keeps the sample's own level.

name   rock
